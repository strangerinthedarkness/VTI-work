# Контраст-устойчивые апостериорные оценки для задачи p(x)-curl

Код и данные численных экспериментов к работе «Контраст-устойчивый апостериорный
контроль погрешности численного моделирования магнитных полей в нелинейных средах:
теория, алгоритм и верификация».

Репозиторий воспроизводит все численные таблицы работы: от валидации оценщика на
аналитических решениях до предельных режимов по контрасту проницаемости и показателю
нелинейности.

## Что здесь есть

| Скрипт | Что считает | Таблица в работе |
|---|---|---|
| `r17_numerics.py` | двумерная скалярная задача: P1-МКЭ, метод Ньютона, оценщики с тремя вариантами граневого веса и невесовой оценщик | таблицы 2 и 3 |
| `r17_phase2.py` | разложение оценщика по вкладам (объём, грани интерфейса, внутренние грани); продолжение по показателю для p < 2 | таблицы 3 и 6 |
| `r17_3d.py` | трёхмерная скалярная задача: тетраэдральная сетка, P1-элементы | таблица 5 |
| `r17_hcurl3.py` | двумерная векторная задача: рёберные элементы Неделека, калибровка tree–cotree, сопряжённые градиенты | таблица 4 |
| `r17_equil.py` | эквилибрация потока (RT0, седловая задача) и проверка гарантированной оценки | раздел 5.6 |
| `r17_extreme2.py` | совместный экстремальный режим: прямое решение линеаризованных систем, продолжение по контрасту и показателю | таблица 6 |
| `r17_extreme3.py` | то же с сопоставлением энергетической и модульной эффективности | таблица 6 |

Результаты каждого запуска сохраняются в JSON рядом со скриптом: имя файла
указано в переменной `OUT` в начале соответствующего скрипта.

## Требования

- Python 3.12 (проверено на 3.12.14)
- NumPy 2.3.5

Другие библиотеки не используются: решатели, сборка матриц и квадратуры
реализованы в самих скриптах. Генераторы случайных чисел не применяются,
расчёты детерминированы — при одинаковых входных данных результат совпадает
бит в бит.

Установка зависимостей:

    pip install numpy==2.3.5

## Как запускать

Каждый скрипт самодостаточен и запускается напрямую:

    python r17_numerics.py
    python r17_3d.py
    python r17_hcurl3.py
    python r17_equil.py
    python r17_extreme2.py

`r17_phase2.py` и `r17_extreme3.py` импортируют функции из `r17_numerics.py`,
поэтому запускать их нужно из той же папки.

Время счёта: от нескольких секунд (двумерные задачи при N ≤ 32) до нескольких
минут (трёхмерные расчёты и совместный экстремальный режим).

## Постановка задачи

Решается уравнение магнитного поля с нелинейной связью индукции и напряжённости
и с переменным показателем p(x):

    ∇ × ( α (1 + |∇ × A|²)^((p(x)−2)/2) ∇ × A ) = J   в Ω,
    A × n = 0                                          на ∂Ω,

где α = μ⁻¹ — вес задачи (обратная магнитная проницаемость), кусочно-постоянный
с контрастом κ = μ_max / μ_min.

Проверка ведётся на аналитических решениях вида

    u* = sin(πx) sin(πy)            (двумерные расчёты)
    u* = sin(πx) sin(πy) sin(πz)    (трёхмерные расчёты)

Нормальная производная этих функций обращается в нуль на интерфейсе x = 1/2,
поэтому условия сопряжения выполняются точно при любых p и κ. Это позволяет
испытывать оценки при предельных контрастах, не внося ошибку согласования данных:
правая часть вычисляется по аналитическому потоку с точностью порядка 1e-10.

## Что измеряется

**Погрешность** — в энергетической мере

    err = ( ∫ α (|∇u*| + |∇u_h|)^(p−2) |∇(u* − u_h)|² dx )^(1/2)

и в модульной мере ρ = ∫ α |∇(u* − u_h)|^p dx. Для p < 2 сравнивать оценщик
с единицей нужно по модульной величине η / ρ^(1/p'); при p ≥ 2 обе меры дают
согласованный результат, и в таблицах приводится энергетическая эффективность.

**Оценщик** состоит из объёмной невязки и скачков нормального потока через грани,
в весовых нормах. Для граневого члена реализованы три варианта веса:
раздельное (одностороннее) взвешивание, арифметическое осреднение и гармоническое
осреднение — их сравнение и составляет содержание раздела 5 работы.

**Гарантированная оценка** проверяется двумя способами: с точным потоком
(проверка алгебры двойственной оценки) и с построенным эквилибрированным потоком
из решения седловой задачи в RT0.

## Основные наблюдаемые закономерности

- Порядок сходимости P1-элементов в энергетической норме — O(h); в векторной
  постановке ротор сходится со вторым порядком.
- Эффективность оценщика с арифметическим граневым весом не зависит от контраста
  при каждом фиксированном p: 10,67 (2D, p = 2), 23,72 (3D, p = 2), и остаётся
  постоянной вплоть до κ = 10⁸.
- Эффективность невесового оценщика растёт как κ^0,45 в двумерных расчётах
  и κ^0,5 в трёхмерных — это и делает его непригодным при высоком контрасте.
- Строки при p = 4 и κ ≥ 10⁴ в трёхмерной задаче из таблицы исключены:
  нелинейный решатель в этих режимах не сходится, что оговорено в работе.

## Воспроизводимость

Параметры каждого расчёта (сетка, контраст, показатель, допуски сходимости)
сохраняются вместе с результатами в JSON. Чтобы повторить любой эксперимент,
достаточно запустить соответствующий скрипт с теми же значениями переменных
в начале файла.
